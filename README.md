# Sos-Floripa

Agente de IA no WhatsApp que recomenda serviços urbanos e de saúde em Florianópolis.

**Status:** protótipo em desenvolvimento. Este repositório ainda não contém os fluxos de automação.

**Como funciona (visão geral)**
- O usuário envia uma mensagem no WhatsApp descrevendo o que precisa.
- Um fluxo de automação interpreta o pedido com IA e devolve uma recomendação de serviço.

**Tecnologias:** n8n, Make, APIs de IA.

Feito por [Mattheus Moraes](https://github.com/moraesmattheus).
